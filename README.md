# ISFP-Connect-X-Plane-Bridge

✈️ ISFP云际模拟飞行连飞平台 X-Plane 10/11/12插件

## 💡 项目说明:

- ** 该项目是ISFP-Connect官方配套子插件，专为 X-Plane 模拟器打造连飞桥接能力。 **

## 🔗 核心功能

- **📡FSD 协议互联**：实时同步模拟器飞行数据，与 ISFP-Connect 客户端双向通信交互。
- **📋游戏内菜单管控**：全部功能集成模拟器原生菜单，支持一键开关、实时配置管理。

## 🛠️ 安装要求

- **操作系统**: Windows 10/11 (推荐)
- **.NET Framework MSBuild 版本**: 18.5.4+cb4e32d21
- **X-Plane**: 10/11/12
- **核心依赖**:
  - C++ 编译运行库
  - CMake Tools 构建工具

## 🚀 快速开始

1. **克隆/下载项目**
2. **安装依赖**:
   - C++
   - CMake Tools
3. **生成库**:
   ```bash
   CMake Build
   ```

## 🛠️ 技术细节

- **FSD 协议**: 完整实现 FSD 协议，支持位置报告、文本消息、心跳等功能。
- **模块化菜单设计**: 插件所有功能独立解耦，可在游戏内自由启停，不影响模拟器原生运行。
